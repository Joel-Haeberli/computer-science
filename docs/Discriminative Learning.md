## Definition

Discriminative models span two type of models:

1. Models which do not use probabilities (closed-form solutions).
2. Models which model the probability $P(y | X; \theta)$ "Whats the probability for $y$ given the input $X$ under the parameters/weights $\theta$?". 

The name comes from the fact, that discriminative models can 'discriminate' the target value $y$, given an input $X$.

They model a direct mapping of any input $X$ to a target value $y$.
